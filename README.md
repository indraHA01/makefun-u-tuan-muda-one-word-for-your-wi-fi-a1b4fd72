# One Word for Your Wi-Fi — "Gaslighting"

Entry word: **Gaslighting**

## Why this angle

The bounty asks for one word that is the funniest and truest description of your Wi-Fi, and the judge rewards a fresh angle on a familiar annoyance. "Gaslighting" is the one word for the experience every home Wi-Fi owner knows by heart: full bars, "Connected", and nothing loads — while the router insists everything is fine and the problem must be you. It never drops out honestly; it stays connected and delivers nothing, then works again the moment you stop watching it. That is not slow, not buffering, not a dead zone — those are the words everyone reaches for. Gaslighting names the relationship: your Wi-Fi tells you you're connected while you stare at a spinning wheel, and somehow you end up apologising to the router.

It lands instantly with no explanation, it is true to how home Wi-Fi actually behaves, and as a network name it is the joke that keeps working every time a guest asks for the password.

## How to run

Requires Node 22 or later. No dependencies, no network, no randomness.

```sh
node main.ts
```

This writes the entry word to `/output/entry.txt` and self-checks the gate first: 1–20 characters, exactly one word, not only whitespace. (To write elsewhere locally, set `OUTPUT_DIR`.)
